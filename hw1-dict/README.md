# ДЗ1. Собственный ассоциативный контейнер и его аудит

Недели 5–8. Закрывает: Л4–Л7. Словарь в трёх реализациях (хеш-таблица, BST,
сбалансированное дерево), общий бенчмарк на трёх нагрузках, атака на хеш-таблицу.

- `ДЗ1__Ассоциативный-контейнер.pdf` — методичка: теория, варианты, протокол замеров, отчёт;
- `task.md` — постановка, ограничения, бенчмарк, атака, отчёт, контрольная точка;
- `io-format.md` — формат тестов и запуска драйвера для `check.py`;
- `keygen.py` — ключи для нагрузок А и Б;
- `gen.py`, `tests/public`, `tests/robustness` — для `check.py`.

    python3 ../check.py hw1-dict          # каждый тест трижды: hash, bst, tree
    python3 ../check.py hw1-dict --bench  # прикидочные замеры

Хеш-таблица из ДЗ1 используется в лабораторной Р3 (`../r3-spam-filter`) —
поэтому на контрольной точке требуется именно она.
