# Формат ввода-вывода — Р1, базовый уровень

Программа запускается с двумя аргументами: путь к входному файлу и путь к
выходному файлу.

    ./solution вход.txt выход.txt

## Вход

Текстовый файл в кодировке UTF-8. Каждая строка — одно событие:

    LOGIN <имя>
    LOGOUT <имя>

Имя пользователя — непустая последовательность букв и цифр без пробелов.
Пустые строки и лишние пробелы между токенами допустимы и игнорируются.
Любая другая строка считается некорректным событием (см. ниже).

## Модель (базовый уровень)

Сессии считаются вложенными: `LOGOUT` закрывает самую позднюю ещё открытую
сессию. Это модель, а не описание реальности — реальные сессии не вложены,
и на повышенном уровне это ограничение снимается.

Состояние — стек имён. Обработка строки за строкой:

- `LOGIN x` — положить `x` на стек.
- `LOGOUT x`, вершина стека равна `x` — снять со стека, засчитать завершённую
  сессию.
- `LOGOUT x`, стек непуст, но вершина не `x` — ошибка `order_violation`.
- `LOGOUT x`, стек пуст — ошибка `logout_without_login`.
- строка не является корректным событием — ошибка `bad_event`.

После конца файла каждая незакрытая сессия даёт ошибку `session_not_closed`
в порядке возрастания номера строки, где она была открыта.

## Выход

Сначала строки ошибок в порядке их обнаружения, по одной на строку:

    ERROR <номер_строки> <код>

где `<код>` — один из `order_violation`, `logout_without_login`, `bad_event`,
`session_not_closed`. Номер строки — с единицы.

Последняя строка — число завершённых сессий:

    SESSIONS <n>

Сравнение вывода потоковое по токенам: конкретные пробелы и переводы строк
значения не имеют, важны сами токены и их порядок.

## Пример

Вход:

    LOGIN alice
    LOGIN bob
    LOGOUT bob
    LOGOUT alice
    LOGOUT carol

Выход:

    ERROR 5 logout_without_login
    SESSIONS 2
