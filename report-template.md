## 1. Постановка и вариант

Что требуется сделать и в чём состоит индивидуальный вариант. Три-четыре предложения.

## 2. Решение

Какие структуры данных использованы и почему именно они. Какой алгоритм реализован, в какой форме (рекурсивной, итеративной), какие приняты решения по представлению данных. Без листингов, на уровне схемы. Половина страницы.

## 3. Асимптотика

Для каждой основной операции:

| Операция | Время | Память | Обоснование |
|---|---|---|---|
| | | | |

Ниже — вывод хотя бы одной из оценок подробно: какие элементарные операции считаются, сколько раз выполняется внешний цикл, сколько внутренний, как получается итог. Если алгоритм рекурсивный, привести рекуррентное соотношение и его решение.

## 4. Замеры

**4.1. Условия.** Число прогревочных прогонов, число повторов, способ агрегации, использованные часы, как обеспечена защита от выбрасывания кода оптимизатором.

**4.2. Результаты.**

| n | Медиана, мс | Мин | Макс |
|---|---|---|---|
| | | | |

*(не менее шести строк)*

**4.3. График.** Время от размера входа. Подписанные оси с единицами измерения.

**4.4. Проверка гипотезы роста.** Предполагаемая функция f(n), таблица отношений t(n)/f(n), вывод о том, подтверждается гипотеза или нет.

| n | t(n), мс | f(n) | t(n)/f(n) |
|---|---|---|---|
| | | | |

**4.5. Расхождения.** Если измеренное поведение отличается от теоретического — где и почему. Возможные причины: кеш, накладные расходы на малых n, выделение памяти, ветвления.

## 5. Худший случай

**5.1. Механизм.** Какое свойство алгоритма делает возможной деградацию.

**5.2. Конструкция входа.** Как построен вход, вызывающий худший случай. Генератор приложен к коду.

**5.3. Замер.** Сравнительная таблица: обычный вход против худшего на одинаковых n.

| n | Обычный вход, мс | Худший вход, мс | Отношение |
|---|---|---|---|
| | | | |

**5.4. Защита.** Что можно сделать, чтобы деградация стала невозможной или маловероятной. Если в работе это реализовано — замер после исправления.

## 6. Масштабирование

Оценка поведения при увеличении входа в 1000 раз, полученная экстраполяцией по разделу 4: ожидаемое время, ожидаемый объём памяти, что откажет первым (время, оперативная память, глубина рекурсии, разрядность счётчика, размер файла).

## 7. Устойчивость к враждебному вводу

**7.1. Свой тест.** Против чьей программы направлен, в чём состоит, какой эффект достигнут.

**7.2. Атаки на свою программу.** Какие тесты получены от однокурсников, какие из них сработали, что исправлено.

**7.3. Обработка некорректных данных.** Краткая таблица: класс некорректного ввода и реакция программы.

## 8. Выводы

Что стало понятно в ходе работы. Отдельно — что оказалось неожиданным: расхождение с ожиданием ценнее подтверждения ожидания и оценивается выше.

## 9. Повышенный уровень

Какие пункты выполнены и с каким результатом. Если ни одного — раздел остаётся с пометкой «не выполнялся».

## 10. Приложение
