# Р3. Спам-фильтр: хеш-таблица и k ближайших

Занятия 6-8. Закрывает: кучи, хеш-таблицы. Собственная хеш-таблица слово→индекс; поиск k ближайших тремя способами (полная сортировка, куча размера k, быстрый выбор) с замером на растущем n.

- `Лаб3__Спам-фильтр.pdf` — методичка: теория, варианты, требования к отчёту;
- `task.md` — постановка, варианты, повышенный уровень, требования к отчёту;
- `io-format.md` — точный формат ввода-вывода, разбор слов, расстояние, порядок соседей;
- `gen.py` — генератор больших выборок для замеров;
- `tests/public`, `tests/robustness` — тесты для `check.py`.

    python3 check.py r3-spam-filter          # каждый тест трижды: sort, heap, select
    python3 check.py r3-spam-filter --bench  # прикидочные замеры
